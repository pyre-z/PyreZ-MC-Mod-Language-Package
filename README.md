# PyreZ 的汉化资源包

Elysium 整合包（Minecraft 1.21.1 / NeoForge）的社区汉化资源包。

## 简介

- 面向 Elysium 整合包：覆盖上百个模组的界面、配置、手册、提示与工具文本
- 增量覆盖模式：仅收录需要覆盖或补充的翻译键，与模组内置中文互不冲突
- 持续维护：术语统一、专名核对，持续跟进模组更新与玩家反馈

## 安装

1. 下载 [Releases](../../releases) 中的 `PyreZ的汉化资源包.zip`
2. 放入 `.minecraft/resourcepacks/` 目录
3. 游戏内「选项 → 资源包」启用，按 `F3+T` 重载（或重启游戏）
