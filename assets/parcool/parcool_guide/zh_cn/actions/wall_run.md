# 竖向跑墙

不要把本动作与[横向跑墙](parcool:actions/horizontal_wall_run.md)混淆。
与其说它是奔跑，不如说它更像跳跃。不过，我确信它是本模组中特别实用的动作。

你可以蹬墙起跳，更垂直地向上攀升。
配合[猫挂](parcool:actions/hang_on.md)和[攀登](parcool:actions/climb_up.md)使用，最多可以翻越 5 格高的障碍物！
这是本模组所能达到的最大高度。

## 使用方法

1. 进行[疾跑](parcool:actions/fast_run.md)
2. 向上看并对墙壁奔跑跳跃，同时按下 <key name="key.jump"/> 键
